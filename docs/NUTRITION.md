# 영양 검증 기준

식단안 하나(한 끼)를 대상으로 열량, 탄단지 비율, 끼니 구성을 검증한다. 결과는 통과 여부와 사유 목록으로 응답에 포함한다. 검증에 실패해도 식단안은 제외하지 않고 사유만 알린다.

영양 값은 식약처 전국통합식품영양성분정보(음식) 표준데이터에서 레시피 이름이 같거나 비슷한 음식을 연결해 가져온 **유사 음식 기준의 추정치**이며 정확하지 않을 수 있다. 연결하지 못한 레시피는 영양 정보가 없다.

출처
- 2025 한국인 영양소 섭취기준 (보건복지부, 한국영양학회): 에너지 필요 추정량, 사전 계산표, 에너지 적정 비율
- 대한비만학회: 체중 감량 시 하루 300~500kcal 감소
- ISSN Position Stand, Protein and Exercise (2017): 한 끼 단백질 20~40g

## 1. 하루 목표 열량 (EER)

내 정보(나이, 성별, 키, 몸무게, 활동량)가 모두 있으면 공식으로 계산하고, 나이와 성별만 있으면 사전 계산표(저활동적 기준, 19세 이상), 나이나 성별이 없거나 19세 미만이면 기본값 2,000kcal를 사용한다. 2,000kcal는 영양성분 표시 기준값이다.

성인(19세 이상, 65세 이상 포함)

| 성별 | 공식 |
| --- | --- |
| 남성 | 662 − 9.53×나이 + PA×(15.91×체중kg + 539.6×키m) |
| 여성 | 354 − 6.91×나이 + PA×(9.36×체중kg + 726×키m) |

소아청소년(3~18세)

| 성별 | 공식 |
| --- | --- |
| 남아 | 88.5 − 61.9×나이 + PA×(26.7×체중kg + 903×키m) + 에너지 축적량 |
| 여아 | 135.3 − 30.8×나이 + PA×(10.0×체중kg + 934×키m) + 에너지 축적량 |

에너지 축적량: 3~8세 20, 9~18세 25

3세 미만은 공식이 없어 기본값을 사용한다.

신체활동계수 PA

| 활동량 | 성인 남 | 성인 여 | 청소년 남 | 청소년 여 |
| --- | --- | --- | --- | --- |
| LOW (비활동적) | 1.00 | 1.00 | 1.00 | 1.00 |
| LIGHT (저활동적) | 1.11 | 1.12 | 1.13 | 1.16 |
| MODERATE (활동적) | 1.25 | 1.27 | 1.26 | 1.31 |
| HIGH (매우활동적) | 1.48 | 1.45 | 1.42 | 1.56 |

## 2. 한 끼 목표 열량

(하루 목표 열량 + 목표 가감) / 3. 목표(goal)는 자유 입력이라 아래 키워드가 포함되면 해당 목표로 본다. 어느 것에도 해당하지 않으면 가감 없이 유지로 본다.

| 목표 | 키워드 | 하루 가감 | 근거 |
| --- | --- | --- | --- |
| 다이어트 | 다이어트, 감량, 저칼로리 | −500kcal | 대한비만학회, 하루 300~500kcal 감소로 주 0.5~1kg 감량 |
| 벌크업 | 벌크업, 근육, 증량 | +300kcal | 근육 증가용 잉여 열량 권고 범위 200~500kcal 안에서 서비스가 고른 값 |
| 유지 | 그 외, 없음 | 0 | - |

## 3. 분량 조절

식단안의 요리마다 분량 배수를 따로 정해 열량과 탄단지 비율을 맞춘다. 배수는 0.5~1.2를 0.1 단위로 시험해 열량 오차(목표 ±10% 이내), 탄단지 비율, 한 끼 단백질 20g 기준을 가장 잘 만족하는 조합을 고른다. 같은 점수면 1.0에 가까운 쪽을 고른다. 요리가 6개를 넘으면 조절하지 않는다. 한도와 허용 오차는 서비스 자체 기준이다. 영양 합계와 검증은 조절한 분량 기준으로 계산한다.

## 4. 끼니 구성 맞춤

LLM이 고른 요리를 아래 구성으로 맞춘다. 넘치는 요리는 앞에서부터 남기고 줄이고, 빠진 칸은 후보에서 채운다. 한 식단안에 이름이 같은 요리는 넣지 않는다. 다른 식단안에서 쓰지 않은 요리를 먼저 쓴다.

| 칸 | 개수 | 채울 때 쓰는 분류 |
| --- | --- | --- |
| 주식 | 1 | 밥 (일품이 있으면 그대로 사용) |
| 국 | 1 | 국&찌개 |
| 반찬 | 3 | 반찬 |

채울 후보가 모자라지 않도록 검색 단계에서 후보에 밥 3개, 국&찌개 3개, 반찬 6개 이상을 보장한다.

## 5. 영양 정보가 없는 요리

식단안에 영양 정보가 없는 요리가 하나라도 있으면 합계와 검증을 하지 않고 verified를 false로 알린다(issues에 사유 한 줄). 분량 조절도 하지 않는다. 이런 식단안이 줄도록 구성 맞춤에서 빈 칸은 영양 정보가 있는 요리부터 채우고, 프롬프트에도 영양 정보가 있는 요리를 우선 쓰도록 안내한다.

## 6. 검증 규칙

| 규칙 | 기준 | 사유 메시지 |
| --- | --- | --- |
| 열량 | 식단안 열량 합이 한 끼 목표의 70%~130% | 열량이 한 끼 목표(N kcal)보다 높습니다 / 낮습니다 |
| 탄수화물 비율 | 에너지의 50~65% | 탄수화물 비율이 기준(50~65%)보다 높습니다 / 낮습니다 |
| 단백질 비율 | 에너지의 10~20% | 단백질 비율이 기준(10~20%)보다 높습니다 / 낮습니다 |
| 지방 비율 | 에너지의 15~30% | 지방 비율이 기준(15~30%)보다 높습니다 / 낮습니다 |
| 주식 | 밥 또는 일품 1개 이상 | 밥이나 일품 요리가 없습니다 |
| 국 | 국&찌개 1개 이상 | 국이나 찌개가 없습니다 |
| 단백질 | 식단안 단백질 합 20g 이상 (한 끼 20~40g, ISSN) | 단백질이 한 끼 권장량(20g)보다 적습니다 |

탄수화물과 단백질 비율은 2020 기준(55~65%, 7~20%)에서 2025 기준으로 바뀐 값을 쓴다.

비율 계산: 에너지는 탄수화물 4, 단백질 4, 지방 9 kcal/g로 환산한 합을 100%로 본다. 레시피 데이터의 칼로리 값과 탄단지 환산값이 다를 수 있어 비율 계산에는 환산 합을 사용한다.

## 7. 응답 형태

식단안(candidates 항목)에 nutrition을 추가하고, recipes 항목마다 portion(분량 배수)을 추가한다.

| 필드 | 설명 |
| --- | --- |
| calorie, carbohydrate, protein, fat | 식단안 합계 |
| carbohydrateRatio, proteinRatio, fatRatio | 탄수화물, 단백질, 지방의 에너지 비율(%). 화면에는 통과 여부 대신 이 비율과 권장 범위를 비교해서 보여 줌(식단 앱과 같은 방식) |
| targetCalorie | 한 끼 목표 열량 |
| verified | 검증을 했는지(영양 정보가 없는 요리가 있으면 false, 이때 합계는 null) |
| passed | 모든 규칙 통과 여부 |
| issues[] | 통과하지 못한 규칙의 사유 목록 |
